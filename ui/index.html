2Connect ChatGPTCopy the URL and authorize access.Next

Keep this app and ChatGPT open side by side. Follow these steps to finish the connection.

  1. Create the connection in ChatGPT

    Enable Developer mode in ChatGPT Settings, then create a connection from Plugins ↗. Name it Codex Link, paste the MCP server URL above, and choose OAuth.

  2. Enter the OAuth settings in ChatGPT

    Under Client registration, use these values. Dynamic Client Registration (DCR) lets ChatGPT create its own client credentials.

    ChatGPT OAuth settings
    Registration methodDynamic Client Registration (DCR)
    OAuth Client ID / Client SecretLeave empty if shown
    Token endpoint auth methodnone
    Base scopesbridge:read

    Under Scopes → Default scopes, paste these four lines:

    files:read
files:write
shell:execute
computer:use

    The computer:use permission is for optional desktop control. You still enable desktop control separately in Codex Link Settings.

  3. Save ChatGPT’s callback URL in Codex Link

    After selecting DCR, copy the full Callback URL shown in ChatGPT. In this app, open Settings → Advanced → Allowed OAuth callbacks.

    Add the copied URL on a new line, keep the existing addresses, and click Save callbacks. Return to Connection → Connect ChatGPT to continue.

  4. Verify the browser you use for ChatGPT

    Click Verify my browser, then Open verification link. Open the link in the same browser and profile where ChatGPT is signed in. This confirms that you own this computer.

    Open the link within 90 seconds. If it expires, click Verify my browser again to create a new one.

  5. Finish the connection in ChatGPT

    Return to ChatGPT and save the connection. Follow the authorization prompt, review the permissions, and select Authorize. Codex Link will show Client connected when authorization succeeds.

Using another MCP client? Add the same URL with OAuth. Its callback address can be added in Settings → Advanced.

Install the desktop helper

From the source project, run:

npm run computer:build

Build on macOS 14+ with Xcode Command Line Tools, or on Windows with the .NET 10 SDK. Move the pointer to a screen corner to stop input; Escape is also a Windows fail-safe. Python is needed only for legacy compatibility.
