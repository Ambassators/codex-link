# Product

## Register

product

## Users

People connecting ChatGPT or another MCP client to their own computer. They want a short setup and clear control over incoming requests.

## Product Purpose

Accept authenticated MCP connections for files, shell commands and optional desktop control. Success is an authorized connection and understandable local approvals.

## Brand Personality

Plain, calm, direct. Preserve the existing utility identity and dark mint palette.

## Anti-references

The previous setup mixed a local AI agent, five setup cards, protocol details and execution controls. Avoid that density and competing actions.

## Design Principles

- One obvious next step: enable the connection, connect ChatGPT, then import Codex work or add projects manually.
- Show progress from actual server state.
- Keep technical configuration in advanced settings.
- Start work in the connected MCP client; approve and monitor it here.

## Accessibility & Inclusion

Use semantic controls, visible keyboard focus, readable contrast, responsive layouts and reduced-motion support. No additional accessibility needs were requested.
